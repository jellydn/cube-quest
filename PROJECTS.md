# Amp Projects

The agent can clone these projects. Use this manifest when a relevant project is not already present in /home/user/workspace.

# Plugin source projects

These projects can provide Amp plugins loaded for this user or workspace. When changing plugin source, clone the relevant project and make and commit the change there. Do not push unless the user explicitly asked you to push or confirms first; pushing publishes the change so other threads, users, or workspaces can load it.

## dunghd/personal-plugins (user plugin source)
git clone 'https://ampcode.com/git/@dunghd/personal-plugins'

## productsway/workspace-plugins (workspace plugin source)
git clone 'https://ampcode.com/git/@productsway/workspace-plugins'
